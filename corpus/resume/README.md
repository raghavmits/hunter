# resume/

Current resume(s), markdown plus source/PDF (PLAN.md FR-16).

One file per resume variant (e.g. a general version and a role-specific one), plus whatever source file it was produced from — the markdown is the version this corpus and any agent reading it can actually parse; the PDF/source stays alongside it for the copy you'd actually send.

Start a new resume file from [`template.md`](template.md).
